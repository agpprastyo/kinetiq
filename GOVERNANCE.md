# Kinetiq Project Governance

This document describes the development and maintenance model of **Kinetiq**.

## Dual-Repository Model

- **Core Repository**: Internal development repository where contributors develop and test core features.
- **Public Repository (`agpprastyo/kinetiq`)**: The official open-source distribution of Kinetiq under the Apache 2.0 license, intended for self-hosting engineers, DevOps teams, and community contributors.

## Issue & Contribution Workflow

- Community bug reports, documentation updates, and feature suggestions are welcome directly via GitHub Issues on `agpprastyo/kinetiq`.
- Pull Requests should follow the guidelines in [CONTRIBUTING.md](CONTRIBUTING.md).
- Releases follow Semantic Versioning (SemVer) with tagged releases and Docker images.
