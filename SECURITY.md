# Security Policy

## Reporting a Vulnerability

We take the security of Kinetiq seriously. If you discover a vulnerability or security flaw, please report it responsibly.

**Please do NOT file public GitHub issues for security vulnerabilities.**

Instead, please submit a report privately via [GitHub Private Vulnerability Reporting](https://github.com/agpprastyo/kinetiq/security/advisories/new) or email `security@kinetiq.dev`.

### What to Include in Your Report
- A clear description of the vulnerability and potential impact.
- Step-by-step instructions or Proof of Concept (PoC) to reproduce the issue.
- The environment / component affected (`apps/api`, `apps/web`, `@kinetiq/sdk`, etc.).

We appreciate your effort in responsibly disclosing security vulnerabilities and will respond as quickly as possible.
